## 命令

```bash
# 桌面（改代码保存后按 r 热重载最快）
flutter run -d windows

# Linux（需要 GTK3 开发库）
flutter run -d linux

# 出安装包
flutter build apk --release
flutter build windows --release
flutter build linux --release
```
